18. LIMITATIONS
  - Consensus = agreement among records, not truth; a systematic error shared by most records becomes the consensus.
  - Citation audit is a keyword heuristic over the whole response; it cannot confirm a source exists or supports a claim.
  - Stall, decline, contradiction and repetition-loop detection are phrase/line heuristics; they only flag, never alter text.
  - Edition headers are detected from lines such as '**1954 FIFA World Cup**' / 'World Cup 1954' / 'Edition: 1954' / '### 6. 1958 - Sweden'; other layouts are missed.
  - 'Reached' = up to the latest edition year that appears in a parsed row or an edition header; an edition skipped inside that range counts as missed.
  - Rows are recovered from merged columns only when a known award name is present in the row text.
  - Rows containing 'does NOT qualify' / 'not a winner' are treated as the model's own exclusions and are not scored as predictions.
  - Name merging uses normalised names and token subsets; a bare surname shared by two players in one edition can be merged.
  - Per-year mode changes the user turn (the placeholder becomes the year) and the system message; do not compare its numbers directly with single-shot runs.
  - Editions absent from the ground-truth file (e.g. 2026) are never scored.
  - Sampling parameters cannot be set through `claude -p`; a call that hits the output-token cap is stored truncated, not retried.
  - Stronger directive levels / escalation change what the model is told; do not mix them with level-1 runs when comparing models.
  - One call per cell and year: small differences between cells may be sampling noise (no replicates).
